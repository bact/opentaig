Accessibility

We are committed to making this website accessible by adhering to Web Content Accessibility Guidelines (WCAG) 2.2 guidelines and supporting full keyboard navigation. While we continually strive to improve accessibility, we recognise there are areas that still need attention. If you encounter any barriers or experience difficulty navigating the site, please open an issue so we can address them.

Data

The full catalog — every open problem, tool mapping, and project-quality/community-health field shown across this site — is also available as a single JSON file: data.json ({{ problem_count }} problems, {{ tool_count }} tools, generated {{ generated_at }}).

This dataset aggregates from several sources, each with its own provenance:

  • Problem text and classification (capacity, target, taxonomy) are from the original Open Problems in Technical AI Governance database — please follow that source's own licence and terms of reuse.
  • Tool metadata (stars, contributors, licence, and similar repository facts) is an aggregation of information from each project's own public repository and package metadata, published by its respective authors. Additional project-quality and community-health signals — the OpenSSF Best Practices badge, OpenSSF Scorecard, and sponsor listings — are aggregated from OpenSSF Best Practices's, OpenSSF Scorecard's, and ecosyste.ms's own public APIs (see References below).
  • The problem–tool mapping, problem–framework/regulation mapping, and their accompanying rationale are original OpenTAIG work, dedicated to the public domain under CC0-1.0 — reuse this part however you like.

(The site's own code is separately licensed, Apache-2.0 — see the repository.)
